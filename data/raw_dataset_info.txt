Dataset Name: Titanic Survival Prediction

Source:
Kaggle - Titanic: Machine Learning from Disaster

Dataset Type:
Binary Classification

Target Variable:
Survived

Number of Records:
891

Number of Features:
12 original features

Description:
The dataset contains demographic and travel information for passengers aboard the RMS Titanic. The objective is to predict whether a passenger survived based on features such as passenger class, age, fare, gender, family information, and embarkation port.

Features Included:

* PassengerId
* Survived
* Pclass
* Name
* Sex
* Age
* SibSp
* Parch
* Ticket
* Fare
* Cabin
* Embarked

Purpose of Dataset:
This dataset is used to demonstrate advanced feature engineering techniques, including polynomial features, interaction features, and mathematical transformations, to improve machine learning model performance.
